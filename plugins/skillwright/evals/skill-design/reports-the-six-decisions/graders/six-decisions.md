The response reports all six decisions that skill-design's Output section requires. Score pass only if every one is present:

1. Which of the three term cases it falls into (and on case 3, the case of the criteria's own vocabulary).
2. The side effect removed and the sense selected — or, on case 3, the criteria written in place of a term.
3. The pinned output form.
4. The trigger width AND the asymmetry that set it (which error it chose to make), not merely "narrow" or "wide".
5. The model generation the criteria were checked against.
6. Each criterion in the body paired with the failure that criterion prevents.

Item 6 is the one most often missing: a list of criteria with no failure named beside them fails this grader even if all the other five are present.
